# Your Drop

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/Ss5pX4hEHe/your-drop)

**Опубликовать в один клик:** нажми кнопку выше, войди в бесплатный аккаунт Cloudflare. На экране настроек укажи:

- Build command: `npm run cf:build`
- Deploy command: `npm run cf:deploy`

База D1 `yourdrop` создаётся автоматически, миграции применяются на шаге deploy. Сайт появится по адресу вида `https://your-drop.<ник>.workers.dev`.

Симулятор открытия кейсов CS2 в стиле Case Battle: кейсы, апгрейд, контракты, инвентарь, виртуальный баланс.
Next.js 15 (App Router) → Cloudflare Workers через OpenNext, состояние профиля в Cloudflare D1.

## Запуск локально

```bash
npm install
npx wrangler d1 create yourdrop        # один раз; скопируйте database_id в wrangler.jsonc
npm run db:local                       # создать таблицу в локальной D1
npm run dev                            # http://localhost:3000
```

`npm run dev` использует локальную D1 из `.wrangler/state` (через `initOpenNextCloudflareForDev`).

## Деплой на Cloudflare

```bash
npx wrangler login
npm run db:remote                      # миграция в облачную D1
npm run deploy
```

`npm run preview` — сборка и локальный запуск в workerd (максимально близко к продакшену).

## Структура

- `src/lib/catalog.json` — 4606 предметов и 169 кейсов с весами (цены case-battle.ac, сентябрь 2026)
- `src/lib/game.ts` — вся игровая логика (чистая функция `act(state, action)`)
- `src/app/api/state/route.ts` — GET состояние / POST действие; профиль по cookie `yd_profile`, оптимистичная блокировка по `version`
- `src/app/api/items/route.ts` — поиск предметов для апгрейда и контракта
- `src/components/*` — Header (пополнение/сброс), CaseView (рулетка), Upgrader, Contract, Inventory

## Правила

- Пополнение: любая сумма, зачисляется через 5 секунд; 1 BCN за каждые 10 ₽
- Открытие 1–10 кейсов за раз, «Быстро» в шапке — прокрутка за ~1 с
- Продажа по цене каталога, сброс баланса с подтверждением
- Апгрейд: шанс = ставка / цена цели × 0,9, максимум 75%
- Контракт: 3–10 предметов → случайный предмет 50–150% суммы

## Что нового (v6, 12 сентября 2026)

- Два размера карточек (переключатель над подборками и в инвентаре)
- Плавный след курсора + ползунки эффектов в меню «Тема» (след, подсветка, анимации)
- Своя цветовая тема: основной цвет, оттенок и насыщенность фона, сохраняется в браузере
- Телефон: панель открытия и кнопка апгрейда закреплены у нижнего края
- Новый звук: щелчки рассчитываются по кривой CSS-анимации и ставятся на аудио-таймлайн заранее
  (`src/lib/sound.ts`, `scheduleTicks`) — попадают в тайминг, не больше ~20 щелчков/с, мягче тембр,
  отдельный «клац» остановки, аккорд выигрыша / перезвон редкого / тихий сигнал неудачи
- «Повторить открытие» в блоке результата; выбранное количество запоминается
- Тематические подборки на главной: «До 100 ₽», «Любителям AWP», «Красный инвентарь», «Охота за ножом»
- Маршруты коллекции (Инвентарь → Маршруты): 5 маршрутов по 5 скинов, награды — рамки и фоны витрины
- Устройства (Инвентарь → Устройства): одноразовый код на 15 минут для второго устройства, API `/api/sync`
- Публичная витрина по ссылке `/u/<id>` с настройкой показа значков, статистики и стоимости
